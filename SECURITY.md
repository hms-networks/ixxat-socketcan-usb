# Security Policy

HMS Networks takes the security of its products and software seriously.
This policy explains how to report a vulnerability in this repository and
what you can expect from us.

## Reporting a vulnerability

**Please report security issues privately.** Do not open a public issue,
pull request or discussion for anything security-sensitive.

Cybersecurity matters, including vulnerability and incident reporting, are
managed centrally for all HMS Networks brands (Anybus, Ewon, Intesis,
Ixxat, owasys, PEAK-System). Please report through either of these pages:

- https://www.hms-networks.com/cybersecurity
- https://www.peak-system.com/contact/cybersecurity-information-and-reporting/

Reports are submitted over an encrypted connection (HTTPS). If you need an
encrypted channel for the ongoing exchange of sensitive details, say so in
your report and we will agree one with you.

## What to include

- Affected repository, component and version (tag or commit)
- A description of the issue and its potential impact
- Steps to reproduce, or a minimal proof of concept
- Your contact details, if you would like to be kept informed

## What to expect

- We acknowledge receipt as soon as possible.
- We verify the report, assess its severity and keep you informed of the
  status.
- Disclosure is coordinated with you. We do not publish details before a
  fix or mitigation is available, and we agree the publication date with
  you.
- Once a remediation is available we publish a security advisory on the
  HMS cybersecurity page. We are happy to credit reporters who wish to be
  named.

## Supported versions

Security fixes are provided for the latest release on the default branch
unless stated otherwise in this repository's README.

## Scope

This policy covers the code in this repository. Vulnerabilities in HMS
Networks hardware or firmware products should be reported through the
pages above, where you will also find our full coordinated vulnerability
disclosure policy.

HMS Networks handles vulnerability reports in accordance with the EU Cyber
Resilience Act (Regulation (EU) 2024/2847).
